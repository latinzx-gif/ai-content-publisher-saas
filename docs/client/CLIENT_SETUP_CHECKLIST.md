# Client Setup Checklist — AI Content Publisher

**Version:** 1.3  
**Date:** 2026-06-04

---

## Before We Begin

You will need the following items ready before the system can be set up. Estimated time: **30–45 minutes**.

---

## 1. OpenAI API Key (Required)

| Item | Detail |
|------|--------|
| What | An API key from OpenAI that enables AI content and image generation |
| Where to get | https://platform.openai.com/settings/organization/api-keys |
| Type needed | `sk-...` standard API key (not organization key) |
| Cost | You pay OpenAI directly per usage. See MONTHLY_COST_GUIDE.md for detailed estimates. |
| Estimated monthly | ฿20–฿240 (see MONTHLY_COST_GUIDE.md for usage scenarios) |
| Setup time | 5 minutes |

- [ ] OpenAI account created
- [ ] Billing set up at platform.openai.com
- [ ] API key generated and copied
- [ ] API key entered in system Settings page

---

## 2. Buffer Account (Required)

| Item | Detail |
|------|--------|
| What | A Buffer account to schedule and publish posts to Facebook |
| Where to get | https://buffer.com |
| Plan needed | Free or paid — free plan supports 1 channel |
| Cost | Free tier available (1 channel, 10 queued posts) |
| Setup time | 10 minutes |

- [ ] Buffer account created
- [ ] Facebook Page connected to Buffer
- [ ] Buffer access token generated
- [ ] Access token entered in system Settings page

---

## 3. Facebook Page Access (Required for Publishing)

| Item | Detail |
|------|--------|
| What | A Facebook Page (not personal profile) to publish posts to |
| Why needed | Buffer publishes to Facebook Pages, not personal timelines |
| If no Page | Create one at facebook.com/pages/create |
| Cost | Free |
| Setup time | 10 minutes |

- [ ] Facebook Page exists
- [ ] Facebook Page connected to Buffer
- [ ] Buffer can see the Page in its channel list

---

## 4. Brand Profile Information

Have the following information ready:

- [ ] **Brand name** — The name of your law firm or accounting firm
- [ ] **Brand description** — 2–3 sentences describing what your firm does
- [ ] **Logo** — High-resolution logo file (for future use, optional now)
- [ ] **Business type** — Legal Advisory or Accounting / Financial Advisory
- [ ] **Target audience** — Who are your posts for? (e.g., SME owners, corporate legal teams, individual taxpayers)
- [ ] **Tone of voice** — Professional, Friendly, Educational, Expert, Corporate, or Simple
- [ ] **Personality** — Trustworthy, Approachable, Serious, Modern, Authority, or Sales-focused
- [ ] **Content rules** — Any disclaimers, required wording, or topics to avoid
- [ ] **Image rules** — Preferred visual styles, brand colors, or imagery to use/avoid

---

## 5. Posting Preferences

- [ ] **Posting frequency** — How many posts per week? (e.g., 3× week, 5× week)
- [ ] **Primary language** — Thai, English, or bilingual
- [ ] **Topics/categories** — What topics will you post about? (e.g., PDPA compliance, labour law, tax filing, VAT, payroll)
- [ ] **Platform** — Currently supports Facebook. Other platforms coming in future updates.

---

## 6. Technical Access

- [ ] System URL: `https://ai-content-publisher-saas.vercel.app`
- [ ] No login required (single-owner mode — the URL is your access point)
- [ ] Admin has access to OpenAI billing dashboard
- [ ] Admin has access to Buffer dashboard
- [ ] Admin has access to Facebook Page settings
