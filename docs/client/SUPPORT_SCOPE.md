# Support Scope — AI Content Publisher

**Version:** 1.3  
**Date:** 2026-06-04

---

## What Is Included

| Area | Included | Detail |
|------|----------|--------|
| System access | ✅ | Full access to AI Content Publisher web application |
| Brand profile setup | ✅ | One-time setup of brand name, tone, audience, and template |
| Template configuration | ✅ | Selection of Legal Professional or Accounting Professional theme |
| Content generation | ✅ | Up to 10 posts per generation via OpenAI GPT-4o |
| Image generation | ✅ | AI background generation + branded text overlay compositing |
| Draft management | ✅ | Review, edit, approve, reject workflow |
| Buffer publishing | ✅ | One-click publish to connected Facebook Page via Buffer |
| Bug fixes | ✅ | Fixes for defects in delivered features |
| Email support | ✅ | Response within 2 business days |
| Documentation | ✅ | Access to all client documentation (setup, user guide, cost guide) |

---

## What Is Not Included

| Area | Not Included | Detail |
|------|-------------|--------|
| Content writing | ❌ | The system generates drafts, but human review and editing is required |
| Legal review | ❌ | Generated content is not reviewed by a qualified lawyer |
| Accounting review | ❌ | Generated tax/financial content should be verified by a qualified accountant |
| API key management | ❌ | Client is responsible for OpenAI and Buffer API key setup and billing |
| Facebook Page management | ❌ | Client manages their Facebook Page and Buffer channel connection |
| Custom template creation | ❌ | Only two templates are available (Legal Professional, Accounting Professional) |
| Multi-platform publishing | ❌ | Currently supports Facebook only via Buffer |
| Analytics and reporting | ❌ | Not included in current version |
| Training | ❌ | Initial walkthrough is provided; ongoing training is an add-on |
| Content strategy | ❌ | Topic selection, posting schedule, and content calendar are client's responsibility |

## Out-of-Scope Items

The following are explicitly **not covered** under any support tier:

- Creating new visual templates or themes
- Adding new publishing platforms (Instagram, LinkedIn, etc.)
- Building analytics dashboards or reporting features
- Multi-user or team collaboration features
- Integration with Google Drive, Notion, or other third-party tools
- Custom branding for the application itself (white-label)
- Mobile app development
- Campaign Factory or 30-Day Planner features
- Direct API integration with Facebook/Instagram/LinkedIn (bypassing Buffer)
- AI model training or fine-tuning
- Legal liability for generated content
