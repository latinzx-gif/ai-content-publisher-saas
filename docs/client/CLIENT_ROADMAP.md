# Client Roadmap

## Recommended Future Upgrades

### Phase 2: Production Publishing Hardening

Goals:

- Verify live Buffer publishing.
- Add safer publish confirmation screens.
- Add retry logic for failed publishing.
- Add published post audit details.

Recommended additions:

- Live Buffer smoke test.
- Publish confirmation modal.
- Failed publish recovery.
- Platform-specific publishing logs.

### Phase 3: Multi-User Review Workflow

Goals:

- Support multiple team members.
- Add approval roles.
- Separate draft author, reviewer, and publisher responsibilities.

Recommended roles:

- Owner.
- Editor.
- Reviewer.
- Publisher.
- Viewer.

### Phase 4: Content Calendar

Goals:

- Plan approved posts by date.
- Schedule posts visually.
- Support upcoming content campaigns.

Recommended additions:

- Calendar scheduling.
- Drag-and-drop content planning.
- Monthly campaign view.
- Publish queue preview.

### Phase 5: Knowledge Source Governance

Goals:

- Make knowledge URLs and manual context easier to manage.
- Improve source traceability for legal content.

Recommended additions:

- Saved knowledge source library.
- Source approval status.
- Source history.
- Link health checks.
- Citation notes for generated drafts.

### Phase 6: Analytics

Goals:

- Measure published content performance.
- Improve future AI generation using performance data.

Recommended metrics:

- Impressions.
- Engagement.
- Clicks.
- Saves.
- Shares.
- Leads or inquiries.

### Phase 7: Brand and Template System Expansion

Goals:

- Expand reusable legal content recipes.
- Standardize output quality.

Recommended templates:

- PDPA checklist.
- Labour law update.
- Contract risk tips.
- BOI promotion guidance.
- Tax planning reminder.
- HR compliance alert.
- SME legal FAQ.

### Phase 8: Client-Ready Polish

Goals:

- Remove demo-oriented copy.
- Improve final production UX.
- Clean up non-blocking build warnings.

Recommended work:

- Copywriting pass.
- Empty-state polish.
- Accessibility pass.
- Mobile QA.
- Unused import cleanup.
- Final production checklist.

## Priority Recommendation

The highest-priority next steps are:

1. Run a live Buffer publishing test.
2. Clean up demo-oriented labels.
3. Add role-based approval if more than one team member will use the system.
4. Add scheduling/calendar publishing.
5. Add analytics after live publishing is active.
